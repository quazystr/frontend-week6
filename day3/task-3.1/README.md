# Day 3, Task 3.1: Каталог с загрузкой

## Что реализовано

- Загрузка ../data/products.json через модуль api.js с функцией getJson.
- Отрисовка карточек через <template> в блок card-list.
- Цена форматируется через product.price.toLocaleString('ru-RU') с добавлением " руб.".
- Во время запроса показывается блок status с модификатором status--loading и текстом «Загрузка товаров...».
- Список card-list скрыт через атрибут hidden во время загрузки.
- После успешной загрузки блок status скрывается, карточки отображаются.

## Проверка с ограничением скорости 3G

Для тестирования в DevTools была включена эмуляция Fast 3G:

1. Открыта вкладка Network.
2. Выбран режим Fast 3G в выпадающем списке throttling.
3. Поставлена галочка Disable cache.
4. Страница обновлена через Ctrl+Shift+R.

Результат:

- Сначала на странице появился синий блок с текстом «Загрузка товаров...» (модификатор status--loading).
- Список карточек был скрыт.
- Через несколько секунд блок status исчез, и появились 8 карточек товаров с отформатированными ценами (например, «4 990 руб.», «18 990 руб.»).

Время загрузки по вкладке Network:

- Статус: 200
- Time: примерно 500 мс для Fast 3G
- Это означает, что пользователь видел блок «Загрузка товаров...» около половины секунды.

При переключении на Slow 3G время увеличилось до примерно 2000 мс, и блок загрузки был виден значительно дольше.

## Проверка дня (выполнена)

- В api.js вызов response.json() находится строго после проверки response.ok.
- Ошибка запроса ловится в try/catch и преобразуется в понятный текст через getErrorMessage.
- В консоли браузера нет «Uncaught (in promise)».
- Состояние запроса хранится в state.status, а не читается из DOM.
- Одна функция render() управляет всеми элементами интерфейса в зависимости от state.status.
