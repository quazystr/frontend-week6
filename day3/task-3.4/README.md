# Day 3, Task 3.4: Один запрос за раз

## Что добавлено

- Кнопка «Обновить» над каталогом, всегда видна (в отличие от «Повторить», которая появляется только при ошибке).
- Во время загрузки кнопка «Обновить» становится недоступной (disabled) и меняет текст на «Загрузка...».
- После завершения загрузки (успех или ошибка) кнопка возвращается в исходное состояние: текст «Обновить», disabled снят.

## Проверка защиты от повторных запросов

1. Включено ограничение скорости Fast 3G во вкладке Network.
2. Поставлена галочка Disable cache.
3. Нажата кнопка «Обновить» — она стала недоступной, текст изменился на «Загрузка...».
4. Открыта вкладка Elements, найдена кнопка «Обновить».
5. Снят атрибут disabled вручную (галочка убрана).
6. Кнопка быстро нажата 5 раз подряд.
7. Открыта вкладка Network.

Результат: в списке запросов только один запрос к products.json со статусом 200. Пять кликов не создали пять запросов.

## Какая строка кода это обеспечивает

Защиту обеспечивает строка в начале функции loadProducts():

```javascript
if (state.status === "loading") return;
```
