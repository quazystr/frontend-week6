## Ответы на вопросы задания

1. Почему во второй строке выводится не массив?
   Потому что функция `getJson` объявлена как `async`. Любая `async` функция мгновенно возвращает объект `Promise`, не дожидаясь завершения внутренней операции (в данном случае — сетевого запроса). Сетевой запрос уходит в фон, а код продолжает выполняться синхронно. Массив данных появится внутри этого промиса только через некоторое время, когда сервер ответит.

2. Что будет, если убрать `await` в строке `const products = await promise;`?
   Переменная `products` останется объектом `Promise`, а не массивом данных.
   Попытка выполнить `console.log(products.length)` выведет `undefined`, так как у объекта Promise нет свойства `length`.
   Если далее в коде попытаться использовать методы массива, например `products.map()`, программа упадет с критической ошибкой: `TypeError: products.map is not a function`. Кроме того, скрипт завершит выполнение раньше, чем придет ответ от сервера.
